# 📊 Fundamentos de Machine Learning com NumPy

Este repositório documenta minha evolução no domínio do NumPy como base matemática para Machine Learning e Deep Learning.

O objetivo é consolidar fundamentos essenciais como álgebra linear, estatística aplicada e manipulação eficiente de dados utilizando computação vetorizada.

---

## 🚀 Objetivo

Desenvolver domínio prático em:

- Operações com arrays multidimensionais
- Vetorização (eliminação de loops)
- Cálculo de médias e estatísticas
- Normalização de dados (Z-Score e Min-Max)
- Manipulação de matrizes
- Preparação de dados para modelos de Machine Learning

---

## 🧠 Conceitos Trabalhados

- `axis=0` vs `axis=1`
- Desvio padrão populacional
- Máscaras booleanas
- Broadcasting
- Precisão numérica (floating point)
- Padronização estatística
